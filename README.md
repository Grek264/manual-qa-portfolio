# Портфолио ручного тестировщика

Подборка учебных и практических QA-артефактов: тест-дизайн, чек-листы, тест-кейсы и матрицы покрытия. Материалы показывают подход к проверке веб-интерфейсов и логики авторизации.

## Состав

### 1. Классы эквивалентности и граничные значения

Файл: `artifacts/01-equivalence-boundaries.xlsx`

- 12 проверок преобразования часов в минуты;
- целые, дробные, отрицательные, большие и нечисловые значения;
- для каждой проверки указано проверяемое свойство.

### 2. Чек-лист карточки товара

Файл: `artifacts/02-product-card-checklist.xlsx`

- функциональная проверка карточки товара интернет-магазина;
- 28 проверок интерфейса и пользовательских действий;
- зафиксированы результаты Pass/Fail и комментарии.

### 3. Тест-кейс авторизации

Файл: `artifacts/03-authorization-test-case.xlsx`

- позитивный сценарий входа по номеру телефона;
- приоритет, предусловия, тестовые данные, шаги и ожидаемый результат.

### 4. Тест-дизайн системы авторизации

Файл: `artifacts/04-authentication-test-design.xlsx`

- 27 тест-кейсов для авторизации, регистрации и восстановления доступа;
- матрица поддерживаемых способов входа для нескольких продуктов;
- отдельные матрицы регистрации и восстановления доступа;
- статусы выполнения сценариев.

## Навыки, представленные в портфолио

- функциональное, позитивное и негативное тестирование;
- техники тест-дизайна: классы эквивалентности и граничные значения;
- подготовка чек-листов и тест-кейсов;
- анализ результатов и фиксация дефектов;
- проектирование покрытия для авторизации, регистрации и восстановления доступа.
