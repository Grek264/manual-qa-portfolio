# Баг-репорт NN-001

## Краткое описание

В фильтре «Классы» на странице списка экскурсий сразу отображаются все 11 значений вместо первых пяти. Кнопка «Показать больше» отсутствует.

## Окружение

- Windows 10
- Chrome 120
- Страница: https://excursium.com/ekskursii-dlya-shkolnikov/list

## Приоритет

Medium

## Предусловия

1. Открыта страница списка экскурсий.
2. Фильтр «Классы» содержит больше пяти значений.

## Шаги воспроизведения

1. Перейти на страницу списка экскурсий.
2. Найти фильтр «Классы».
3. Проверить количество отображаемых значений.
4. Проверить наличие кнопки «Показать больше».

## Фактический результат

Сразу отображаются все 11 значений. Кнопка «Показать больше» отсутствует.

## Ожидаемый результат

По умолчанию отображаются первые пять значений. Остальные значения становятся доступны после нажатия кнопки «Показать больше».
